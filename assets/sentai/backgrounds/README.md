# Fondos independientes

Coloca aquí los JPG de fondo, con los nombres de `../nombres.txt`.
Ejemplo: `mirai-sentai-timeranger.jpg`, en 1920 × 1080.
No coloques aquí el logo si quieres un fondo distinto.

Tras subir los archivos, pulsa Ajustes → Toku Kino → Actualizar imágenes de Sentai.
Cuando falte el fondo de una serie, sus metadatos conservan la imagen de
ShadowRangers. Su póster vertical no se reemplaza.
